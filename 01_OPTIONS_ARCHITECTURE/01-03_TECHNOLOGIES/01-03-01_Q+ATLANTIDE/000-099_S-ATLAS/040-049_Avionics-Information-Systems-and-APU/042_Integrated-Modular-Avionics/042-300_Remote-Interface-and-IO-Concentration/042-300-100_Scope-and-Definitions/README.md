# 042-300-001 — Scope and Definitions

**Node:** 042-300_Remote-Interface-and-IO-Concentration · **Subject:** 001

- Remote interface unit: a zonally installed unit providing acquisition, conditioning, digitization, concentration and output-drive channels, with a network end system.
- Acquisition channel: one characterized input path (analog, discrete, or legacy serial bus) from a source signal to a validated digital value.
- Concentration: the grouping of many channels into few network publications under declared refresh and latency properties.
- Output channel: one characterized command path from a received network value to a monitored electrical output.
- Out of scope here: the sensors and effectors themselves (their functional chapters), network contract governance (042-200), hosted consumer functions (042-400), unit host structure and harnessing (structures and wiring standard practices).
