# 042-400-009 — Evidence and Certification Data

**Node:** 042-400_Hosted-Function-Partitioning-and-Configuration · **Subject:** 009

- Evidence set: hosting plan and rationale, budget verification reports, usage-domain declarations and interference evidence per hosted set, configuration consistency reports, acceptance records per function and per integrated configuration, and the configuration index per loaded standard.
- Loadable-item identification and version verification follow the onboard-maintenance interfaces (REF 045); digital-product-passport hooks are exposed through the same channel.
- Programme applicability, effectivity and instance sizing are out of scope for the taxonomy: they are declared in the programme impact studies and PBS layers that map onto this subject.
