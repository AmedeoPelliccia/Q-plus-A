# 042-400-100 — Scope and Definitions

**Node:** 042-400_Hosted-Function-Partitioning-and-Configuration · **Subject:** 001

- Hosted function: an application allocated to platform partitions, owned by its functional chapter, accepted for hosting here.
- Partition: the spatial and temporal execution container guaranteed by the platform; allocation binds functions to partitions.
- Resource budget: the declared envelope a hosted function may use — processing time, memory, network contracts, IO publications and commands.
- Usage domain: the bounded set of platform mechanisms and resource patterns a hosted set actually uses, against which interference evidence is produced.
- Integrated configuration data set: the single versioned artifact binding partition tables, budget tables and contract references.
- Out of scope: platform mechanisms themselves (042-100), network contract governance (042-200), acquisition behavior (042-300), runtime health decisions (042-900), function design (functional chapters).
