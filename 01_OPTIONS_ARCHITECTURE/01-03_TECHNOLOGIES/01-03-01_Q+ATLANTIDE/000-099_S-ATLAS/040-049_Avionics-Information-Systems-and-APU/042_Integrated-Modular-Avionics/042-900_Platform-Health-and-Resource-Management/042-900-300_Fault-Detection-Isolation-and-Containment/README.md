# 042-900-300 — Fault Detection Isolation and Containment

**Node:** 042-900_Platform-Health-and-Resource-Management · **Subject:** 003

- Detection coverage is declared per failure class and substantiated as evidence (009); undetected classes are named, not ignored.
- Isolation resolves events to fault containment regions; ambiguity groups are declared where single-region resolution is not achievable.
- Containment consequences are graded: inhibit, restart, reallocate, reconfigure — each consequence class has declared authority and limits.
- False-alarm and missed-detection rates are managed properties with analysis on record, not tuning folklore.
