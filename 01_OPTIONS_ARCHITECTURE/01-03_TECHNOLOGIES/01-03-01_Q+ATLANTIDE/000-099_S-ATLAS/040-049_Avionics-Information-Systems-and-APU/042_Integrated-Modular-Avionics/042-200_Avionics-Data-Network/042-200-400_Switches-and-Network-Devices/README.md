# 042-200-400 — Switches and Network Devices

**Node:** 042-200_Avionics-Data-Network · **Subject:** 004

- Switch functions: static forwarding per loaded tables, ingress policing of traffic contracts, domain filtering, and fault containment of babbling or mis-configured subscribers.
- Device configuration is a loadable, versioned item under the same configuration discipline as the tables it enforces (042-200-006).
- Device built-in test and traffic observability hooks feed platform health and resource management (042-900).
- Device qualification and environmental data are evidence items.
