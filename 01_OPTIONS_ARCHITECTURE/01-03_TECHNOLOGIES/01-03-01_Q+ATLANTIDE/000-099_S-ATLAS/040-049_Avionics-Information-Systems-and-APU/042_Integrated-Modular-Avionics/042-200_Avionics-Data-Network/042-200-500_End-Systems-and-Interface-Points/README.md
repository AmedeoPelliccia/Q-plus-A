# 042-200-500 — End Systems and Interface Points

**Node:** 042-200_Avionics-Data-Network · **Subject:** 005

- End systems on processing modules: the module provides the end-system resource (042-100); its transmit contracts and reception filters are network configuration owned here.
- End systems on remote interface units (042-300) follow the same contract discipline; concentration ratios and acquisition latency belong to 042-300.
- Non-IMA subscribers (sensors, effectors, standalone units) join through characterized interface points; their contracts are declared like any other and their domain assignment follows 002.
- Interface control between the network and each subscriber class is a controlled document set.
