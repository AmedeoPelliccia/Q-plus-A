# 042-100-800 — Evidence and Certification Data

**Node:** 042-100_Core-Processing-Platform · **Subject:** 008

- Evidence set of the platform: platform acceptance data, core-software
  lifecycle data, hardware qualification data, and the configuration index
  per installed standard.
- Loadable-item identification and configuration reporting follow the
  onboard-maintenance interfaces (REF 045); digital-product-passport hooks
  are exposed through the same channel.
- Programme applicability, programme deltas and instance sizing are out of
  scope for the taxonomy: they are declared in the programme impact studies
  and PBS layers that map onto this subject.
