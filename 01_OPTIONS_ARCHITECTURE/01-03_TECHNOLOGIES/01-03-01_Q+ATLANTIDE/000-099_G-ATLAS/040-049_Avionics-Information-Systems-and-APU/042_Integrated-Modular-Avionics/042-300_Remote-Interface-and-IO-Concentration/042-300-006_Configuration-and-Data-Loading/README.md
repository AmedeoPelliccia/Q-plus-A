# 042-300-006 — Configuration and Data Loading

**Node:** 042-300_Remote-Interface-and-IO-Concentration · **Subject:** 006

- Per-unit configuration (channel mapping, conditioning parameters, publication grouping, safe-state declarations) is a versioned, consistency-checked loadable item.
- Pin-to-signal mapping tables are controlled items shared with the installation definition; a mapping change is a configuration event, never a workshop improvisation.
- Loading, configuration reporting and version verification follow the onboard-maintenance interfaces (REF 045).
