# 042-300-000 — Remote Interface and IO Concentration Overview

**Node:** 042-300_Remote-Interface-and-IO-Concentration · **Subject:** 000

- Remote interface units acquire, condition and digitize zonal sensor signals, concentrate them onto the deterministic network, and drive effector outputs under monitored, characterized behavior.
- The function exists to keep analog reach short and digital reach long: acquisition happens near the signal, transport happens on the network, computing happens on the platform.
- This node owns the interfacing and concentration function; the units' network contracts are governed in 042-200 and their configuration allocation in 042-400.
