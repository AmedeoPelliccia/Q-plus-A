# 042-200-000 — Avionics Data Network Overview

**Node:** 042-200_Avionics-Data-Network · **Subject:** 000

- The avionics data network is the deterministic communication backbone of the integrated modular avionics: it carries partition-to-partition and platform-to-subscriber traffic under guaranteed bandwidth, latency and integrity properties.
- This node owns the network as a system: architecture, transport determinism, devices, configuration governance and time distribution.
- Physical end-system electronics live with their host units (042-100 modules, 042-300 remote units); the network node governs how they communicate, not how they are built.
