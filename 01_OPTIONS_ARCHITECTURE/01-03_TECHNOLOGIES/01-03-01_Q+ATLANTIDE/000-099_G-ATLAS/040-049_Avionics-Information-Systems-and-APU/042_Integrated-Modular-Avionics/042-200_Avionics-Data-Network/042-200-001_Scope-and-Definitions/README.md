# 042-200-001 — Scope and Definitions

**Node:** 042-200_Avionics-Data-Network · **Subject:** 001

- Deterministic network: a network whose worst-case delivery properties (bandwidth, latency, jitter, ordering, integrity) are established by construction and demonstrated by analysis, not by measurement alone.
- End system: the network access function of a subscriber unit, enforcing its transmit contracts and filtering received traffic.
- Switch: the active network element forwarding, policing and segregating traffic per the loaded configuration.
- Traffic contract: the configured envelope (rate, frame size, priority, redundancy class) a flow may use; contracts are configuration-controlled items.
- Out of scope here: end-system host hardware (042-100, 042-300), partition resource allocation (042-400), health-management function (042-900), information-security domain policy (046-500), physical harness installation (wiring standard practices).
