# 042-200_Avionics-Data-Network

**Chapter:** 042_Integrated-Modular-Avionics · **Node:** 042-200

## Scope

Deterministic avionics data network: network architecture and topology, deterministic transport and traffic contracts, switches and network devices, end-system interface points, network configuration governance and time distribution. End-system hardware resides on processing modules (042-100) and remote interface units (042-300); partition-level configuration is 042-400; network health monitoring feeds 042-900.
