# 042-200-002 — Network Architecture and Topology

**Node:** 042-200_Avionics-Data-Network · **Subject:** 002

- Redundancy doctrine: independent network planes with unit-level dissimilar routing where integrity targets require it; plane independence is preserved end to end.
- Topology is a declared, configuration-controlled architecture item: switch count and placement, segregation of domains, and growth ports are design decisions with recorded rationale.
- Domain segregation separates flight-critical, cabin/operator and open-world traffic classes; gateways between domains are explicit, characterized items coordinated with 046-500 security-domain policy.
- Growth: reserved switch ports, bandwidth headroom and contract-table margins are declared network reserves.
