# 042-100-000 — Core Processing Platform Overview

**Node:** 042-100_Core-Processing-Platform 

- The core processing platform is the shared computing resource of the integrated modular avionics: standardized processing modules hosted in cabinets, executing hosted applications under partitioning guarantees.
- Hosted applications belong to their functional chapters; this node owns the platform hardware, its core software as a delivered component, its power and cooling interfaces, and module-level provisioning.
- Platform positions itself as the certification anchor of the avionics suite: incremental acceptance of hosted functions builds on the platform acceptance established here.
