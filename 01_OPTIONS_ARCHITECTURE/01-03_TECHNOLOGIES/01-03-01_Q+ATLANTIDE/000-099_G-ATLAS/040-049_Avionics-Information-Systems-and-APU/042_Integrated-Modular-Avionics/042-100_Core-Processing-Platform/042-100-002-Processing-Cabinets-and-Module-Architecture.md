# 042-100-002 — Processing Cabinets and Module Architecture

**Node:** 042-100_Core-Processing-Platform 

- Cabinet set and installation zones; slot count, growth slots and spare provisioning policy are configuration-controlled items.
- CPM types are minimized to a small standardized set; type differences (compute class, IO class) are declared, not improvised.
- Redundancy doctrine: platform capacity supports the availability and integrity targets of the most demanding hosted set; dissimilarity, where required, is a platform-level declaration inherited by 042-400 budgets.
- Mechanical integration of racks and support structure belongs to 053; this node declares envelope, mass and interface requirements only.
