# 042-100-001 — Scope and Definitions

**Node:** 042-100_Core-Processing-Platform · **Applicability:** eWTW+hBWB

- Cabinet: the installed enclosure providing slots, backplane, power distribution and cooling paths for processing modules.
- Core Processing Module (CPM): a replaceable computing unit providing processing, memory and network end-system resources to hosted partitions.
- Platform: the combination of cabinets, modules and core software offered to hosted-function suppliers as a characterized computing resource.
- Role vocabulary follows the industry IMA development model: platform supplier, hosted-application supplier, system integrator, certification applicant. Responsibilities are contractual and evidence-bearing.
- Out of scope here: partition allocation and configuration data (042-400), deterministic network configuration (042-200), remote IO electronics (042-300), health-management function (042-900), hosted applications (their functional chapters).
