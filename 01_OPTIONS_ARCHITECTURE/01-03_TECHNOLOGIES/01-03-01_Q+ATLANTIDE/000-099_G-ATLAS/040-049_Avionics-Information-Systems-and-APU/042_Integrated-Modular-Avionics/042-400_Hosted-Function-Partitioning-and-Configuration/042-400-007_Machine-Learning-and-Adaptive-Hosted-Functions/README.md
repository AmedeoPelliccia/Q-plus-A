# 042-400-007 — Machine Learning and Adaptive Hosted Functions

**Node:** 042-400_Hosted-Function-Partitioning-and-Configuration · **Subject:** 007

- Hosted machine-learning functions follow the certification-aware governance of 01-06 (Neural Networks) and land in partitions under the same allocation, budget and evidence discipline as any hosted function.
- Frozen-model discipline: inference-only execution; the model is a versioned loadable item with declared provenance; training and adaptation happen off-board under 01-06 governance.
- In-service adaptation or on-board learning has no hosting path under this node until a certification basis for it exists; the prohibition is doctrinal, not technical.
- Model data, training-set provenance and performance envelopes are evidence items accompanying the acceptance record.
