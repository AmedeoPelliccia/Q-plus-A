# 042-400-000 — Hosted Function Partitioning and Configuration Overview

**Node:** 042-400_Hosted-Function-Partitioning-and-Configuration · **Subject:** 000

- This node is the governance layer of the integrated modular avionics: it decides what runs where, under which guaranteed resources, with which evidence — and keeps the result one consistent, versioned configuration state.
- Doctrine: one aircraft configuration state at a time; every hosted function enters through allocation, budgeting and acceptance, never by installation alone.
- The platform stays generic (042-100); the functions stay functional (their chapters); the meeting point is governed here.
